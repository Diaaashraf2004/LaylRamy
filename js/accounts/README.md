# قسم الحسابات المالية (Accounts Department)

## 📌 المسؤوليات والوظائف
يختص هذا القسم بإدارة الحسابات المالية والخزائن الفرعية والبنوك، ويشمل:
1. **عرض وإدارة الحسابات:** عرض قائمة الحسابات وأرصدتها وتحديث التبويبات وإعادة تعيين نموذج الحساب (`renderAccounts`, `showTab`, `resetAccountForm`, `getLiveAccounts`).
2. **المعاملات المالية للحسابات:**
   - إضافة إيراد مالي مباشر للحساب (`handleIncomeAddition`).
   - تسجيل سحب أو مصروف مباشر من الحساب (`handleExpenseAddition`).
   - التحويل المالي بين الحسابات والخزائن مع التحقق من كفاية الرصيد وتسجيل حركات السيولة (`handleTransfer`).
   - تسوية وضبط رصيد الحساب (`handleBalanceAdjustment`).
3. **الإيداعات ومودال الإيداع:** فتح وتأكيد الإيداعات النقدية في الخزائن والحسابات (`openDepositModal`, `confirmDeposit`).
