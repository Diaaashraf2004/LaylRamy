# قسم الاستقطاعات والمقاصة الخفية (Deductions Department)

## 📁 هيكل المجلد
يحتوي مجلد `js/deductions/` على الوحدات البرمجية المسؤولة عن نظام الاستقطاع المخفي (Hidden Margin / Deduction System):

1. **`deductions-core.js`** (~435 سطر):
   - حقن حقول الاستقطاع المخفي في واجهة البيع السريع (`injectDeductionFieldsToQuickSell`).
   - ربط وتعديل حسابات الربح اللحظي ورأس المال عند تفعيل الاستقطاع.
   - اعتراض وتعديل حفظ الفواتير السريعة (`quickSell`) لتسجيل مبلغ الاستقطاع كالتزام مالي منفصل باسم الطرف المستفيد.
   - دعم التعديل السلس للفواتير التي تحتوي على استقطاعات مسبقة.

## 🛡️ معايير الجودة والأمان
- الملف مكون من 435 سطراً (أقل من سقف الـ 600 سطر المحدد في برومبت المايسترو).
- معزول داخل IIFE مستقل لحماية المتغيرات وتجنب أي تلوث للنطاق العام.
- مطابقة تامة 100% للهاشات والأداء الوظيفي.
