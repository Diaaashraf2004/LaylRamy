# قسم التقارير المالية والطباعة (Reports & Analytics Department)

## 📁 هيكل المجلد
يحتوي مجلد `js/reports/` على الوحدات البرمجية المسؤولة عن إعداد وتوليد وعرض التقارير المالية والإحصائية، طباعة الفواتير وكشوف الحسابات، وتصدير البيانات:

1. **`reports-print.js`** (~521 سطر):
   - طباعة كشف حساب مورد/دائن (`printCreditorStatement`).
   - طباعة كشف حساب عميل (`printCustomerStatement`).
   - تصدير واستيراد البيانات العامة للنظام (`exportData`, `importData`).
   - توليد محتوى HTML لكافة تقارير الطباعة الموحدة مع التعقيم ضد هجمات XSS (`generateReportHTML`).
   - طباعة فاتورة بيعة معلقة أو فاتورة مسجلة رسمية (`printPendingSaleAsInvoice`, `inv_printInvoice`).

2. **`reports-daily.js`** (~262 سطر):
   - عرض وتهيئة جدول تقرير مبيعات اليوم والفترات (`displaySalesReport`).
   - حذف فاتورة من عرض التقرير فقط دون المساس بالمخزون (`removeSaleFromReportOnly`).
   - استخراج وتدقيق المبالغ المالية من نصوص تفاصيل العمليات (`parseAmountFromLogDetails`).
   - التفريغ الشامل لبيانات وسجلات التقارير بعد تأكيد المستخدم وحارس الحفظ (`deleteAllReportData`).

3. **`reports-monthly.js`** (~135 سطر):
   - توليد وتحليل تقرير المبيعات والأرباح الشهري الشامل (`generateMonthlySalesReport`).
   - تجميع مبيعات العملاء وتصنيف الأصناف الأكثر ربحية وحركة في الشهر المحدد.

4. **`reports-expenses.js`** (~237 سطر):
   - توليد وعرض تقرير المصروفات التفصيلي بالخزائن والحسابات (`generateExpensesReport`).
   - المعالجة السحابية والتخزين المؤقت لبيانات المصروفات وتجميعها حسب الفئات (`generateExpensesReportExternal`, `processExpensesData`, `extractAmountFromText`).
   - التغليف التلقائي لتحديث واجهة المصروفات عند تحديث الواجهة العامة (`updateUI`).
   - حذف قيد المصروف يدوياً واسترجاع رصيد الخزينة وحسابه الأصلي (`deleteExpenseEntry`).

## 🛡️ معايير الجودة والأمان
- جميع الملفات أقل من 600 سطر وفقاً لقواعد برومبت المايسترو.
- مطابقة تامة لهاشات الدوال الـ 100% مع الـ Baseline.
- حماية ضد هجمات حقن النصوص (XSS Protection) في جميع قوالب الطباعة.
